# Meta-Programs Learning Deck — Design Spec

## Purpose
A flashcard-style learning tool for NLP Meta-Programs. It sits alongside the existing NLP Repository and does not replace the existing Meta Programs dropdown.

## Categories
1. Cognitive — Thinking
2. Emotional — Feeling
3. Cognitive — Choosing
4. Semantic — Meta meta-programs

## Card Front
- Number
- Title
- Category
- Continuum bar
- Visual scene placeholder
- One-line summary

## Card Back / Detail Panel
- Definition
- Language cues
- Behavioural signs
- Strengths
- Blind spots
- Coaching prompts
- Example
- Personal notes placeholder

## UI Behaviour
- Category tabs filter cards.
- Card grid shows cards in the selected category.
- Selecting a card opens a detail panel.
- Flip Card toggles front/back emphasis.
- Continuum component must support two-point, three-point, and multi-point continuums.
- Visual images are not required yet; use visualScene text or placeholders.

## Important Principles
- Meta-programs are filters and preferences, not fixed traits.
- People can move along a continuum depending on context.
- No good/bad framing.
- Keep tone authoritative, practical, and coaching-oriented.
